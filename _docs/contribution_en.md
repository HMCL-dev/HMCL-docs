If you believe you are capable of adding high-quality help documentation to HMCL, or would like to correct mistakes, you can submit a Pull Request or open an Issue in the [https://github.com/HMCL-dev/HMCL-docs](https://github.com/HMCL-dev/HMCL-docs) repository.

Alternatively, you can join our [Discord](https://discord.gg/jVvC7HfM6U) or the [HMCL User Group](/_docs/groups.md) to give feedback to HMCL.

You can also help us translate the documentation into other languages by creating a `<name>_en.md` file next to the original article and opening a Pull Request. See the "Multilingual" section of the repository README for the conventions.
