> [!NOTE]
> Using Steve, Alex, or a local skin image file: you may be unable to join multiplayer, and other players may not be able to see your skin\
> Using LittleSkin or a Blessing Skin server: in multiplayer, players who use the **same method** as you can see your skin, but other players cannot

Open HMCL and go to the **account list**, then click the `Upload/Edit Skin` button of the offline-mode account shown below (in the red box).

![](/assets/img/docs/offline-skin/img1_1.png)

![](/assets/img/docs/offline-skin/img1_2.png)

- `Default`: use the default random skin
- `Steve`: use the Steve skin
- `Alex`: use the Alex skin
- [Local skin image file](#local-skin-image-file)
- [LittleSkin](#littleskin)
- [Blessing Skin server](#blessing-skin-server)

## Local Skin Image File

After selecting a local skin image file, set the resource path for the skin and for the cape as needed, then click Confirm.

![](/assets/img/docs/offline-skin/img2.png)

## LittleSkin

First, you need a LittleSkin account. [Register](https://mcskin.littleservice.cn/auth/register) and [log in](https://mcskin.littleservice.cn/auth/login).

Then go to [Character Management](https://mcskin.littleservice.cn/user/player) and check your character name. If you do not have one, click the add new character button to add one.

You can change the skin and cape of this account name in [My Wardrobe](https://mcskin.littleservice.cn/user/closet).

![](/assets/img/docs/offline-skin/img3_1.png)

The character name must match the character name of the offline-mode account in HMCL. If it does not match, switch to the corresponding offline-mode account in HMCL, or create a new offline-mode account whose name matches the character name.

![](/assets/img/docs/offline-skin/img3_2.png)

Once you have confirmed that the offline-mode account's character name matches, click **LittleSkin** to sync the skin from LittleSkin.

![](/assets/img/docs/offline-skin/img3_3.png)

## Blessing Skin Server

Go to Character Management and check whether the character name matches the character name of the offline-mode account in HMCL. If it does not match, switch to the corresponding offline-mode account in HMCL, or create a new offline-mode account whose name matches the character name.

You can change the skin and cape of this account name in My Wardrobe.

![](/assets/img/docs/offline-skin/img4_1.png)

Go to Configuration Generator and, as shown in the figure below, find the URL under `CustomSkinLoader`. Copy it into HMCL to sync the skin of this account name on the Blessing Skin server.

![](/assets/img/docs/offline-skin/img4_2.png)

![](/assets/img/docs/offline-skin/img4_3.png)
