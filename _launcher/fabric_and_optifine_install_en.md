In HMCL's automatic installation, if you select Fabric or OptiFine first, HMCL will report that they are incompatible with each other.

However, with a few simple steps described in this document, you can install a Fabric & OptiFine client at the same time.

The principle is to install the OptiFabric Fabric mod, which takes the official OptiFine and makes it compatible with Fabric at runtime.

**If you use OptiFine purely to improve performance, use the zoom button, or get dynamic lighting, [other mods](https://lambdaurora.dev/optifine_alternatives#/) can provide these features individually with more reliable compatibility.**

## How to Do It

### 1. First select a version, select Fabric, and install it.

![Install the Fabric client](/assets/img/docs/fabric_and_optifine_install/1.gif)

*Note: if you want to add other Fabric mods, it is recommended to install **Fabric API** as well, since some Fabric mods depend on it.*

### 2. Obtain and install the OptiFabric mod & OptiFine

#### Obtaining

- **1) Obtain OptiFabric: you can get it from its [MCMod download page (recommended)](https://www.mcmod.cn/download/1703.html), its [CurseForge page](https://www.curseforge.com/minecraft/mc-mods/optifabric/files/all), or by searching for mods in HMCL**

#### Installing

Open the game management page for the game version you want to install mods for, switch to Mod Management, and add the OptiFabric mod & OptiFine on this page.

![Install mods](/assets/img/docs/fabric_and_optifine_install/11.gif)

**Then check in Mod Management whether the OptiFabric mod & OptiFine are present!**

Once you have checked, you are done — just launch the game.
